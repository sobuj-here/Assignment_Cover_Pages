## 📖 Overview

Standardized assignment cover pages ensure consistent, professional formatting across academic submissions. This repository contains ready-to-print vector PDF cover sheets tailored for university courses, including designated layouts for specific faculty designations (Lecturer, Senior Lecturer, Associate Professor) and general-purpose templates.

## ✨ Standard Cover Page Fields

All templates provide structured, clearly delineated spaces for essential academic information:
- **Course Details:** Course Title, Course Code, Section, and Semester.
- **Student Information:** Student Name, Student ID / Roll Number, Program / Department, and Batch.
- **Instructor Information:** Submitted To (Instructor Name), Designation, and Department.
- **Submission Timeline:** Date of Submission and Academic Session.

## 🖨️ Printing & Editing Instructions

1. **Direct Printing:**
   - Open any `.pdf` template in your preferred PDF viewer (Adobe Acrobat, Edge, Chrome).
   - Press `Ctrl + P` (or `Cmd + P`).
   - Ensure the paper size is set to **A4 (210 × 297 mm)** and page scaling is set to **Actual Size (100%)**.
2. **Digital Editing (Fill Before Printing):**
   - Use any PDF editor (such as Adobe Acrobat Reader, PDF-XChange Editor, Foxit, or Canva) to add fillable text fields.
   - Alternatively, print the template and complete the fields by hand.
